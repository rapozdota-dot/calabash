# Audit findings

Severity reflects the impact on architecture and research claims.

## High

| Finding | Evidence | Documentation decision |
| --- | --- | --- |
| **H1. Training provenance is missing.** The deployed graph proves a TorchVision Small backbone, but a trained FlatBuffer cannot establish the starting weights, fine-tuning/freeze schedule, training loss settings, registered but pruned modules, or which PyTorch checkpoint produced it. | `assets/model/model.tflite` metadata and ops 0–106. [Validator:16–33](../tool/validate_ios_release.py#L16-L33), [upstream TorchVision wrapper](https://github.com/ultralytics/ultralytics/blob/v8.4.191/ultralytics/nn/modules/block.py#L1449-L1506) | Mark ImageNet initialization and checkpoint identity as unverified until the original model YAML, training notebook, initialization log, checkpoint hash and export record are available. |
| **H2. The study's exact run-to-artifact mapping is unverified.** The V7 pair is identifiable in Git. Locally available APKs and IPA contain V5 artifacts. The metadata for the two V7 models points to differently named dataset YAMLs, with no evidence here about sample/split equivalence. | [Model and archive hashes](SYSTEM_AUDIT.md#models-and-deployment-evidence), [IPA source-info:3–12](../.tmp-run22-artifact/Calabash-source-info.txt#L3-L12), [comparison workflow at acee015](https://github.com/rapozdota-dot/calabash/blob/acee0150c30b37f623e253c14691216291c7f41e/.github/workflows/android-release.yml) | Bind each reported run to the model and package hashes, exact train/validation/test split manifest, inference policy and device/session provenance. Cite the available pair as audited V7 artifacts until that mapping is supplied. |
| **H3. Smaller file size does not imply fewer operations or lower latency.** The hybrid has about 26% fewer file bytes and 17.5% more estimated convolution MACs than the audited baseline. Its prototype branch uses 128 hidden channels at 160² compared with the baseline's 64. | Hybrid ops 299–308, baseline ops 282–291, [computation method](LAYER_BY_LAYER.md#size-and-computation) | Use the actual 128-wide prototype branch in the figure. Give file size, folded convolution scalars, convolution-only operation estimates and measured device latency distinct metrics. |

## Medium

| Finding | Evidence | Documentation decision |
| --- | --- | --- |
| **M1. The hybrid changes more than the feature extractor.** YOLO-style SPPF, C2f feature aggregation and the Segment topology remain, but three adapters, narrower fusion maps and class towers, and a wider Proto branch differ from the baseline. The active MobileNet ends at the 96-channel IR11 output. | Hybrid ops 107–199 and 228–255/299–308. Baseline ops 99–182 and 211–238/282–291. [Graph comparison](HYBRID_ARCHITECTURE.md#comparison-with-the-v7-standalone-artifact) | Describe retained topology and state the measured widths. Avoid attributing all performance or accuracy differences to an isolated backbone change. |
| **M2. The active graph has no independent species-verification classifier.** Scores and masks can be plausible for a wrong object. The historical V7 diagnostic reports above-threshold, mask-supported predictions on 8 of 57 dataset-labeled negative images. Its source images and result files are unavailable in this checkout, so the result was not independently reproduced. | Hybrid t558/t559, [README:39–44](../README.md#L39-L44), [historical diagnostic, lines 17–37](https://github.com/rapozdota-dot/calabash/blob/0171722ad9a880900cf7da9239ee3d7818b2b323/docs/hybrid_v7_false_positive_audit.md#L17-L37) | Caption the three outputs as maturity class scores for detected instances. Treat non-calabash rejection as an evaluated performance question. |
| **M3. Diagnostics and device outputs measure different stages.** Python reports raw candidates and may see different inputs after image resizing. Flutter filters by score and geometry, runs NMS, reconstructs supported masks, and applies additional live tracking policy. | [diagnose_model.py:12–54](../tool/diagnose_model.py#L12-L54), [ModelService:425–506](../lib/services/model_service.dart#L425-L506), [live publish:902–947](../lib/providers/live_camera_provider.dart#L902-L947) | Label raw LiteRT scores, still-photo outputs and live tracked results by pipeline and use matched inputs for parity claims. |
| **M4. Compatible shapes do not establish coordinate units.** The V7 export normalizes `xywh` by 640 and Flutter rescales by 640. An alternate model with the same shape could export pixel units. The current signature validation checks type/shape and the iOS release guard checks metadata and hash. | Op 309 constant t86, [ModelService:823–843](../lib/services/model_service.dart#L823-L843), [signature validation:1030–1110](../lib/services/model_service.dart#L1030-L1110), [validator:16–63](../tool/validate_ios_release.py#L16-L63) | Specify normalized center-format coordinates in the model contract and verify that contract when documenting future exports. |
| **M5. Native V7 execution remains unverified in this audit.** Reference execution passed all 312 ops with finite outputs. The archived simulator evidence points to V5 standalone. | [Synthetic execution](ARCHITECTURE_EVIDENCE.md#synthetic-reference-execution), [archive:6–12](../.tmp-run22-artifact/Calabash-source-info.txt#L6-L12) | Scope the current validation to graph inspection and reference execution. Cite V7 native smoke/device evidence only when tied to its hash. |
| **M6. The export differs from the tagged SPPF constructor.** The V7 hybrid applies SiLU before the first pool. The tagged v8.4.191 SPPF constructor uses `act=False` for `cv1`. Metadata identifies the exporter version and cannot resolve whether an earlier checkpoint or a source override supplied the live block. | Hybrid ops 116–118, [tagged SPPF constructor:195–220](https://github.com/ultralytics/ultralytics/blob/v8.4.191/ultralytics/nn/modules/block.py#L195-L220) | Draw SiLU in both SPPF projections and use the original checkpoint or constructor to reproduce the source graph. |

## Low

| Finding | Evidence | Documentation decision |

| **L1. Generic runtime naming can obscure the model variant.** The model service comment says MobileNetV3 classification is not integrated, which can be misread as the backbone being absent. The splash, runtime configuration and legacy `yolo_inference_ms` metric use YOLOv8n-seg labels for the hybrid as well. | [ModelService:127–131](../lib/services/model_service.dart#L127-L131), [ModelService:185–188](../lib/services/model_service.dart#L185-L188), [live provider:1004–1009](../lib/providers/live_camera_provider.dart#L1004-L1009), [splash:166–198](../lib/screens/branded_splash_screen.dart#L166-L198), [README timing:211–213](../README.md#L211-L213) | Use the artifact hash and variant metadata for reporting. State that the hybrid has MobileNetV3-Small feature extraction and YOLO maturity classification. |
| **L2. README smoke examples are limited.** The blank and cucumber examples and the reported high score on one field photo provide case evidence. They supply neither sample-wide rejection accuracy nor physical-device confirmation. | [README:60–65](../README.md#L60-L65) | Cite the example scope alongside any larger evaluation and include source artifacts and tested build identities. |
| **L3. The release test assumes the host's default decoding can read README.** Under Windows CP1252 one of nine tests errored. The same suite passed with Python UTF-8 mode. | [Workflow test:60](../tool/test_performance_recording_workflow.py#L60) | Record the reproducible validation command with `-X utf8`. |

## Priority evidence for the manuscript

Collect the original architecture definition and checkpoint, the initialization and export commands, training dataset manifests and run logs, and the study's per-variant package/session hashes. These establish ImageNet initialization, exact source construction, split equivalence, and which trained artifact generated each reported result.
