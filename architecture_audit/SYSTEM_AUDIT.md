# Calabash system architecture audit

## Scope and verdict

Audited the Calabash Flutter repository at commit `9528022f3176ad0b8592aaf6ca86df5382ecd714`, branch `feature/mobilenetbackbone-yolov8nseg-final`. The starting worktree was clean. Discovery covered the checked-out tree, nested hidden and ignored model candidates, Git history reachable from local refs and remote-tracking refs, and the packaged models available in local build outputs. The repository provides mobile source, diagnostics, build automation, and trained TFLite exports. The training environment is represented only by references in export metadata and historical notes.

The bundled V7 export executes one integrated instance-segmentation network. Its active feature extractor is TorchVision MobileNetV3-Small through inverted residual block 11. Three projected backbone features feed an Ultralytics SPPF and a YOLOv8-style top-down and bottom-up neck. One `Segment` head produces boxes, maturity-class scores, mask coefficients, and shared mask prototypes. Training initialization and the mapping from manuscript experiment rows to artifact hashes remain unverified. See [hybrid graph](HYBRID_ARCHITECTURE.md) and [evidence ledger](ARCHITECTURE_EVIDENCE.md).

## Audit validation

- Direct FlatBuffer reads and SHA-256 checks covered both current files, three historical model blobs, and the model entries in the two local Flutter APKs and archived IPA. The checked-in metadata validator passed on the V7 asset.
- An independent Python reference evaluator executed all 312 operators using the export constants and existing NumPy/SciPy. All operator results matched the stored shape and float32 dtype and were finite on a neutral synthetic tensor. [Runtime results](ARCHITECTURE_EVIDENCE.md#synthetic-reference-execution)
- All nine Python release/workflow tests passed with `python -X utf8 -B -m unittest discover -s tool -p 'test_*.py'`. The first invocation under the Windows default code page failed while reading UTF-8 README text. UTF-8 mode resolved the test run without repository edits.
- The operator ledger, local file and line links, and the Mermaid graph structure and tensor routes passed structural checks. The official Mermaid renderer was unavailable.
- Targeted Flutter unit tests could not start. The sandbox denied access to the Flutter SDK cache lock at `C:\flutter\bin\cache\lockfile`.
- A native V7 LiteRT, Flutter simulator, or physical-device run was not reproduced in this audit. The Windows Python environment lacked LiteRT, and the available package source did not resolve the requested wheel. The reference run measures execution semantics on a synthetic input and supplies no device-performance, accuracy, or experiment-reproduction evidence.
